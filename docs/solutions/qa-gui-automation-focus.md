# QA 화면 자동화가 전면 앱으로 키 입력을 흘린 사고

## 증상
QA가 osascript로 앱에 키를 보냈는데 Orbit이 아닌 전면의 다른 앱(사용자가 쓰던 창)에 입력이 들어갔다.

## 원인
System Events의 키 입력은 대상 창이 아니라 그 순간 전면 앱으로 간다. 앱 실행·창 전환이 늦거나 사용자가 창을 바꾸면 전면 앱이 달라진다.

## 해결
키를 보내기 전에 전면 앱이 Orbit인지 확인하고, 아니면 보내지 않고 중단한다.

## 다음에 미리 할 것
- GUI 자동화 키 입력마다 직전에 전면 앱 이름을 확인하는 단계를 둔다.
- 가능하면 키 입력 대신 앱 안에서 검증할 수 있는 경로(테스트, 프론트 브라우저 확인)를 먼저 쓴다.
- 확인이 어려운 항목은 사용자 확인 대기로 남긴다.
