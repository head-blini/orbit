# 실패할 수 없는 테스트

- 증상: 새 테스트 17개가 통과했지만, 구현을 한 줄씩 망가뜨려도(변이) 통과하는 곳이 6군데 있었다(REVIEW R2~R7). 또 `includes` 부분 문자열 대조 버그를 "한계"라는 이름의 테스트로 고정했다(REVIEW N3).
- 원인: 사례가 다른 규칙에 먼저 걸려 대상 분기를 실제로 타지 않았다. 버그를 고치지 않고 현재 동작을 그대로 단언했다.
- 해결: 리뷰어가 사본에 변이를 넣어 확인했고(변이 9개, 각각 정확히 1개 테스트 실패), 사례를 대상 분기만 타게 바꿨다.
- 다음에 미리 할 것: 테스트마다 대상 분기를 꺼 보고 실패하는지 확인한다. 알려진 버그는 "한계" 테스트로 굳히지 말고 고치거나 이슈로 남긴다.
