# Claude Code 플러그인 동작

- 에이전트·스킬은 `plugin:name` 범위 이름으로만 호출된다(맨 이름은 not found). 훅의 `agent_type`도 범위 이름이다.
- 메인 세션을 플러그인 에이전트로 지정하면 그 에이전트의 tools 밖(스킬 목록, 데스크톱 앱 도구)이 보이지 않는다.
- 프로젝트 설정의 마켓플레이스 선언은 폴더 신뢰 후에만 적용되어 헤드리스 `claude -p`에서는 로드되지 않았다. `--settings <파일>`로 실행하면 선언된 마켓플레이스가 사용자 수준에 자동 등록된다(부작용).
- 역할 정의 파일은 세션 시작 때 로드된다. 새로 만든 역할은 새 세션에서만 호출된다.
- directory source 플러그인은 캐시가 아니라 그 자리에서 로드됐다.
- 다음에 미리 할 것: 스크립트·훅·문서의 역할 이름은 범위 이름으로 쓰고, 헤드리스 검증은 부작용(사용자 수준 등록)을 감안해 설계한다.
