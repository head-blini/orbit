# 훅 수신 서버와 설치 도우미 (마일스톤 ②)

## http 훅은 SessionStart에 안 된다
- 증상: SessionStart를 http 훅으로 등록하면 Claude Code 2.1.317이 받아들이지 않는다.
- 원인: 이 버전은 SessionStart에 http 훅을 지원하지 않는다(실측).
- 해결: 이벤트를 11개로 확정하고 SessionStart를 뺐다.
- 다음에 미리 할 것: 새 이벤트를 http 훅으로 등록하기 전에 실제 Claude Code 버전에서 그 이벤트가 도는지 실측한다. 문서만 믿지 않는다.

## tiny_http 0.12.0의 큰 본문 DoS
- 증상: 토큰 없는 요청 하나(Content-Length > 1024)로 서버가 멈추거나 죽는다(재현됨).
- 원인: tiny_http는 Content-Length가 1024를 넘는 요청의 남은 본문을 drop에서 타임아웃 없이 할당하고 읽는다. 토큰 검증 전에 일어난다.
- 해결: tiny_http를 버리고 std `TcpListener` 파서로 교체했다(본문 크기 제한·읽기 타임아웃을 우리가 쥔다).
- 다음에 미리 할 것: 인증 전 경로를 라이브러리에 맡기는 의존성은 "큰 본문·느린 클라이언트"로 먼저 찔러 본다.

## 설치 도우미: 같은 내용이면 쓰지도 백업하지도 않는다
- 증상: 사용자 settings 백업이 77개 쌓였다.
- 원인: 재현되지 않았다. 수정 뒤 클릭 1번 = 백업 1개, 같은 내용 재설치 = 백업 0개를 QA가 확인했다.
- 해결: 병합 결과가 현재 내용과 같으면 쓰기·백업을 건너뛴다.
- 다음에 미리 할 것: 설정을 고치는 기능은 "같은 입력 두 번"의 부작용(파일·백업 수)을 테스트에 넣는다.

## QA는 실제 settings를 건드리지 않는다
- 방법: 디버그 빌드 전용 `ORBIT_CLAUDE_SETTINGS`로 임시 사본을 가리키고, WebView2 원격 디버깅으로 앱을 조작한다. 사용자의 실제 `settings.json`은 대상이 아니다.

## 수용한 잔여 위험
- S1: 다른 프로세스가 http 훅 포트를 먼저 가로챌 수 있다. 수용했고 후속은 `.orbit/decisions.md` 12번(gitignore).
