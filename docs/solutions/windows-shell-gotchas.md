# Windows 셸 함정

- 증상/원인/해결:
  - Node 24에서 `node --test <디렉터리>`는 실패한다 -> 파일을 지정한다.
  - PowerShell 5.1에서 문자열을 node로 파이프하면 BOM이 붙어 `JSON.parse`가 실패한다 -> 파일로 쓰거나 BOM 없이 전달한다.
  - Bash 도구를 거치면 JSON 안의 역슬래시 경로가 깨진다 -> 슬래시를 쓴다.
  - 명령 문자열 안의 글자만 보고 판정하는 훅은 heredoc·테스트 데이터 속 `git push` 글자를 오탐한다.
- 다음에 미리 할 것: 검증 명령은 파일 단위로, 경로는 슬래시로 쓰고, 훅 테스트 데이터에 위험 명령 글자를 넣을 때 오탐을 예상한다.
