# Windows 경로 기반 권한 판정

- 증상: engineer가 `.orbit/runs/r1/Review.md`를 `VERDICT: PASS`로 써서 `REVIEW.md` 보호를 우회할 수 있었다(리뷰어가 재현, REVIEW B1).
- 원인: 소유자 표 정규식이 대소문자를 구분했다. NTFS는 구분하지 않고, 아직 없는 파일은 realpath가 대소문자를 바로잡지 못한다. 8.3 짧은 이름, `::$DATA`, 끝의 점도 같은 부류다.
- 해결: 경로 비교를 대소문자 무시(`i`)로 하고, 대소문자만 다른 변형 사례를 테스트에 넣었다.
- 다음에 미리 할 것: 경로로 권한을 판정하는 코드는 대소문자 변형, 짧은 이름, 대체 데이터 스트림, 끝의 점/공백 사례를 처음부터 테스트한다.
