# QA 미검증 항목과 환경 제약 수용

## 증상
QA가 실제 맥 앱(WebKit)을 못 띄우고 Chromium으로만 검증해 VERDICT가 FAIL로 남는다(루프 설정 run: 미검증 6건).

## 원인
QA VERDICT는 미검증 항목이 하나라도 있으면 PASS가 될 수 없다. 환경 제약은 QA가 스스로 면제할 수 없다.

## 해결
사용자가 미검증을 수용한다고 명시 승인(채팅)한 뒤 Lead가 STATE.json 승인에 기록하고, CHANGELOG에 "사용자 확인 대기로 수용(날짜)" 한 줄을 남긴다.

## 다음에 미리 할 것
- 맥 앱에서만 확인되는 항목(select 펼침 위 Esc, 숫자 입력, VoiceOver)은 계획 단계에서 "사용자 확인 대기"로 분류해 둔다.
- ROADMAP 체크는 QA·보안 전 웨이브의 librarian 태스크로 미리 처리해, 출고 뒤 문서 커밋이 늘지 않게 한다.
- 테스트를 먼저 실패시킬 때 없는 export는 `import * as m`으로 불러 모듈 로드 실패를 피한다.
