# 레이드 스프라이트 시안 (v2 — 참고 이미지 방향)

그래프 칸을 RPG 레이드로 보여 주는 안의 캐릭터 시안. 코드에는 아직 쓰이지 않는다.

- [sprites.svg](sprites.svg) — 본 시트. 우리 4명암, 모든 그림 4배, 카드(검은 제목 탭 + 8×8 아이콘)마다 대기/공격.
- [sprites-green.svg](sprites-green.svg) — 비교용. sprites.svg를 `<image>`로 불러 필터로 4명암 → 초록 4톤(#1e381e #47703a #98bf7c #dff0c8)을 1:1 치환. 그림을 따로 갖지 않으므로 sprites.svg와 같은 폴더에 있어야 하고, 브라우저에서 파일로 직접 열어야 보인다(Orbit 미리보기 창처럼 data: URL로 여는 곳에서는 빈 화면).
- 참고 이미지는 비율·표현·카드 구성만 따랐고, 픽셀은 새로 찍었다(추적·복사 아님).

## 팔레트 — 정확히 4색 (design/tokens.json)

| 번호 | 값 | 토큰 | 쓰임 |
|---|---|---|---|
| 0 | `#1c1e18` | ink | 외곽선, 눈, 입, 제목 탭 |
| 1 | `#5c6052` | dark | 어두운 옷(마법사 로브·도적), 몬스터 피부, 효과선 |
| 2 | `#b4b8a4` | light | 투구·갑옷, 두건, 중간 면 |
| 3 | `#f8f8ec` | paper | 얼굴, 하이라이트, 칼날·방패, 불꽃 심 |

투명 = 배경. 반투명·안티에일리어싱 없음. 시트에 들어 있는 fill은 이 4개뿐(점검함).

## 그리드

| 종류 | 크기 | 비고 |
|---|---|---|
| 용사 | 32×32 | 머리 15×13(y5–17) · 몸 y18–24 · 다리 y25–30, 발 외곽선 y31. 머리가 키의 절반 가까이 |
| 슬라임 | 24×24 | 질문·한 줄 수정 |
| 고블린 | 32×32 | 작은 작업 |
| 오크 | 40×40 | 중간 작업 |
| 드래곤 | 64×48 | 큰 작업. 왼쪽 x0–17은 불꽃 자리 |
| 상태 아이콘 | 16×16 | 머리 위 |
| 카드 탭 아이콘 | 8×8 | 2배로 탭 안에 paper색 |

바닥선은 그리드 맨 아래 줄. 표시 배율은 정수배만, `shape-rendering="crispEdges"` / `image-rendering: pixelated`.

## 그리는 규칙

- 외곽선 1px, 4방향(대각 모서리 비움). 부품마다 외곽선을 둘러 겹쳐 그려 부품 사이에도 1px 선.
- 빛은 왼쪽 위: 면의 오른쪽·아래 1px은 한 단계 어둡게, 왼쪽·위는 한 단계 밝게.
- 얼굴: 눈 2×2(왼쪽 위 1px 반짝임), 볼 1px(light), 입 1px. 공격 프레임은 입을 벌림(2px).
- 용사는 오른쪽, 몬스터는 왼쪽을 본다(화면에서 용사 왼쪽 · 몬스터 오른쪽).
- 공격 효과(휘두름 곡선, 반짝임 ✦, 속도선, 땀방울, "!!")는 dark/ink로 같은 그리드 안에, 빈 칸에만.

## 프레임

| 대상 | 프레임 |
|---|---|
| 용사 7종 | 대기 · 공격 |
| 슬라임 · 고블린 · 오크 | 대기 · 공격 |
| 드래곤 | 대기 · 공격(물기) · 공격(불뿜기) |
| 상태 아이콘 | 1장씩, 방어막만 닫힘/깨짐 |

권장 재생: 작업 중일 때만 대기↔공격 0.25초 교대. `prefers-reduced-motion`이면 대기 고정. HP(진행률) 막대는 스프라이트 밖 UI.

## 직업 ↔ 역할

| 직업 | 역할 | 실루엣 핵심 | 공격 |
|---|---|---|---|
| 기사단장 | Lead(지휘만) | 깃털 투구 · 망토 · 왼쪽 장대 깃발(오르빗 고리 문양) | 깃발을 앞으로 들어 흔듦 + 곡선, 외침 |
| 마법사 | 설계 | 끝이 꺾인 큰 뾰족 모자 · 긴 로브 · 구슬 지팡이 | 지팡이 앞으로 + 반짝임 |
| 전사 | 개발(여러 명) | 둥근 투구 · 십자 방패 · 검 | 큰 검 휘두름 + 곡선 두 줄 |
| 궁수 | 리뷰 | 뾰족 후드 · 활 · 화살통 | 시위 당김 + 화살 |
| 도적 | 보안 | 두건 + 복면 · 목도리 날개 · 단검 둘 | 단검 찌르기 + 곡선·속도선 |
| 힐러 | 디버거 | 둥근 두건 · 밝은 로브 · 십자 지팡이 | 지팡이 들어 올림 + 십자 반짝임 |
| 성기사 | QA | 뿔 투구 · 큰 십자 방패 · 망치 | 망치 내려침 + 곡선 |

| 몬스터 | 작업 크기 | 공격 |
|---|---|---|
| 슬라임 | 질문·한 줄 | 뛰어오름 + 땀방울 |
| 고블린 | 작은 작업 | 단검 휘두름 |
| 오크 | 중간 작업 | 도끼 치켜듦 + 포효 "!!" |
| 드래곤 | 큰 작업 | 물기 · 불뿜기 |

| 아이콘 | 뜻 |
|---|---|
| 말풍선 `!` | 사용자 답 대기 |
| `z` `Z` | 졸음(오래 대기) |
| ✕ 눈 얼굴 | 쓰러짐(실패) |
| 방어막 닫힘(자물쇠) | 체크포인트 안 열림 |
| 방어막 깨짐 | 체크포인트 통과 |

## 점검 기록

- v1(32px, 작은 머리) → 참고 이미지 반영 v2: 머리 13→15px 폭, 눈 1×2 → 2×2 + 반짝임, 볼 추가, 갑옷·두건을 한 단계 밝게, 카드 프레임·탭 아이콘, 몬스터 공격 프레임과 드래곤 물기 추가. 전사는 뿔 → 둥근 투구+십자 방패, 뿔 투구는 성기사로.
- 실루엣 점검(전부 ink로 칠해 비교): v1에서 기사단장(깃발+망토가 네모 덩어리)과 힐러(지팡이가 두건에 붙음)가 안 갈려 깃발 장대를 x3으로, 힐러 지팡이를 x26으로 떼어 냄.
- v2 렌더 뒤: 기사단장 공격의 깃발이 4px로 작아 안 읽힘 → 장대를 세우고 깃발을 8×8로 키우고 고리 문양 추가.
- 시트 저장 형식: 각 명암 층을 `<path d="Mx yhWvHh-Wz…">`(픽셀 직사각형만, 대각선 없음)로 묶었다. 개별 `<rect>`로는 160KB가 넘어 같은 픽셀을 64KB로 줄인 것. 확대해도 경계가 정확히 픽셀에 맞는다.
- 남은 메모: 2배로 줄이면 오크 얼굴은 눈만 읽힌다(3배 이상 권장). sprites-green.svg는 미리보기 창에서 상대 경로를 못 읽어 직접 확인하지 못했고, 필터 색 치환만 확인했다.
