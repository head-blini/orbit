1. 채팅 패널: **틀과 빈 상태만.** 확정 배치대로 채팅 상자와 입력 줄 모양만 만들고 입력은 비활성 + "⑥에서 연결" 안내. 대화·승인 기능은 마일스톤 ⑥.
2. 그래프 데이터: **훅 + 메인 로그.** SubagentStart/Stop 훅과 메인 세션 로그의 Agent 도구 호출로 노드와 상태를 만든다. 서브에이전트 로그 파일(`subagents/agent-*.jsonl`) 안은 계속 읽지 않는다. 노드별 토큰·소요 시간은 얻을 수 있는 것만.
3. DB(`orbit.db`): **④ 뒤 별도 run.** ④는 메모리 그대로. 재시작하면 훅 전용 정보(권한 대기 등)는 사라지고 로그에서 복원되는 것만 남는다.
4. 임시 표시: **상세 패널로 모으기.** 세션 줄은 "폴더 이름 + 상태 기호 + 마지막 활동 시각"(id·출처는 세션을 고르면 상세 패널에). 타임라인 목록은 삭제. 훅 설치·제거·상태·안내문과 로그 폴더 경로는 상세·하네스 패널의 "설정" 묶음으로, 액정 "폴더 열기" 버튼도 여기에.
6. 서브에이전트 실패(`✕`): **확인될 때만.** Agent 도구의 실패 훅(PostToolUseFailure)이나 로그 `tool_result`의 오류 표시가 확인될 때만 `✕`, 그 밖의 종료는 "끝남"(기본 상자). SPEC의 "성공"은 "끝남"으로 고친다. 수용한 위험: 실패한 서브에이전트가 끝남으로 보일 수 있다(모든 세션·모든 서브에이전트).
7. 유휴 기준: **10분.** 마지막 이벤트 후 10분 동안 조용하면 "멈춤(추정)", 새 이벤트가 오면 다시 작업 중. 권한 대기는 다음 Pre/PostToolUse·Stop·StopFailure·SessionEnd에서 해제.
8. CSP: **이번에 켠다.** `default-src 'self'`, 그림은 asset 출처만, 글꼴은 'self'. dev가 깨지면 `devCsp`.
