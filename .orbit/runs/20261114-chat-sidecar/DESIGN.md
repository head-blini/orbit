# DESIGN — 20261114-chat-sidecar (마일스톤 ⑥: 채팅 패널)

디자인 문법은 다시 정하지 않는다: 4명암·색 없음, 이중 테두리 패널, layout_v4 배치(채팅 = 아래 칸 왼쪽+가운데 두 열), 픽셀 글꼴은 제목·메뉴·버튼·상태 문구만, 도구 호출 목록 없음, 화면 용어 "체크포인트"(`.orbit/decisions.md` 63~107행 최종·확정 줄). 범위·동작은 이 run의 BRIEF·DECISIONS(`Dn` = DECISIONS n번).

- 기준 시안: `design/reference/layout_v4.html` — 첫 화면 채팅 칸 = 대표 상태(권한 카드 대기). 그 아래(휠로 내림) "채팅 상태별 변형" 9칸, 각 656×220(960×640 창의 채팅 칸 크기). 스크립트·외부 요청 없음.
- 토큰: `design/tokens.json`에 `chat.*` 추가.

## 1. 사용자 흐름

1. 세션 미선택 → 채팅 가운데 "세션을 고르면 그 폴더에서 대화를 시작합니다", 입력 줄 꺼짐.
2. 왼쪽에서 세션을 고름 → "보내면 {폴더 이름} 폴더에서 새 대화를 시작합니다", 입력 줄 켜짐(`▼` 깜빡임), `보내기`는 글이 있을 때만 활성.
3. Enter(또는 `보내기`) → 기록 맨 위 "─ 새 대화 · 폴더: {이름} ─", 내 말이 바로 붙음. 입력 줄이 "Claude가 일하고 있다… [중단]"으로 바뀜. 대화 중에는 폴더 고정(다른 세션을 골라도 이 대화는 그대로).
4. 답이 text_delta마다 늘어남, 끝에 깜빡이는 네모 커서. 도구를 쓰는 동안 글이 안 늘어도 커서와 "일하고 있다…"가 남는다(도구 목록은 보이지 않음).
5. 권한 요청 → 기록 끝에 권한 카드, 입력 줄 문구 "고를 때까지 기다리고 있다…" + `중단`. 고르면 카드는 결과 한 줄로 접히고 답이 이어진다.
6. AskUserQuestion → 질문 카드. 하나 고르기는 선택지를 누르면 바로 보냄. 여러 개는 토글 뒤 카드 안 `보내기`. 질문이 하나면 입력 줄이 열려 직접 답을 쓸 수 있음(+`보내기` + `중단`).
7. 끝 → "완료 · 추정 비용 $0.0123", 입력 줄 다시 켜짐. 같은 대화로 이어 보냄(D1).
8. `중단` → 버튼 비활성(글자 그대로) → "중단됨", 대기 카드는 "→ 거부됨 (중단)"/"→ 답하지 않음 (중단)"으로 접힘, 입력 다시 켜짐.
9. 실패(시작 실패 포함) → "✕ 오류: {사유}" 한 줄, 입력 다시 켜짐.
10. `새 대화`(제목 줄 오른쪽) → 기록을 비우고 2의 상태(지금 고른 세션 기준). 실행 중에는 비활성.

### 2.1 메시지

- 두 칸 격자: 말한 이 칸 56px(픽셀 12px, ink: "나" / "Claude") + 8px + 글 칸. 글은 **일반 글꼴 13px/1.5, ink, 글자 그대로**(`white-space: pre-wrap`, `overflow-wrap: anywhere`, 마크다운 해석 없음 — `#`·백틱이 그대로 보임).
- 내 말 = 글 칸 안에서 내용 폭만큼의 **1px ink 테두리 상자**(모서리 0, 좌우 8px). Claude 답 = 테두리 없음. 구분은 이름표 + 상자 유무(색 아님).
- 메시지·카드·끝 줄 사이 8px. 글 칸 폭 제한 없음(넓은 채팅 그대로).
- 스트리밍 커서: 7×13px ink 네모, 글 끝에 2px 띄워 붙임, 1s step 깜빡임(기존 `.blink`). 끝나면 사라짐.

### 2.2 첫 줄

"새 대화 · 폴더: {cwd 마지막 폴더 이름}" — 픽셀 12px dark, 가운데, 양옆 1px 점선 dark가 남는 폭을 채움. 이름이 길면 말줄임. 대화마다 한 번, 기록 맨 위(함께 스크롤).

### 2.3 권한 카드

- 위치: 글 칸에 맞춰 왼쪽 64px 들여씀, 최대 폭 640px. 모양 = 그래프 노드와 같은 작은 RPG 대화창(2px ink + 안쪽 이중선, 모서리 6px, 패딩 8px 12px, 안쪽 줄 사이 4px).
- 1줄: "{도구 이름} 실행을 허용할까요?" (픽셀 12px).
- 2줄 대상: 고정폭 13px, 왼쪽 2px ink 세로줄 + 8px, 글자 그대로 줄바꿈. 6줄(117px) 넘으면 카드 안 스크롤(Tab으로 닿음, aria-label "명령"/"파일"). 대상: Bash = `command`, Edit·Write·Read·NotebookEdit = `file_path`(또는 `notebook_path`), WebFetch = `url`, 그 밖 = 입력 JSON 한 줄, 300자에서 "…".
- 3줄 메뉴: `허용` `거부` `이 세션 동안 ({범위})` — 픽셀 12px 글자 버튼(테두리 없음, 높이 24px, 사이 16px). **`▶` 커서는 하나**: 포커스·hover한 항목 앞, 아무것도 아니면 첫 항목(허용) 앞. hover 바탕 light. 범위: Bash "(이 명령만)", 그 밖 "({도구} 전부)"(D4).
- 답한 뒤: 메뉴가 결과 한 줄로 바뀜(픽셀 12px dark): "→ 허용함" / "→ 거부함" / "→ 이 세션 동안 허용함 (이 명령만|{도구} 전부)" / "→ 거부됨 (중단)"(중단·signal abort·앱 종료). 1·2줄은 남긴다.

### 2.4 질문 카드 (AskUserQuestion)

- 같은 카드 모양·위치. 질문마다: `header` = 기존 `.tag` 칩(1px 테두리, 픽셀) / 질문 글 = 일반 13px ink / 선택지 세로 목록.
- 선택지 버튼(폭 전체, 높이 ≥24px, 2px 4px): 기호 칸 24px + `label`(픽셀 12px) / 그 아래 `description`(일반 11px dark, hover 시 ink). hover 바탕 light.
- 하나 고르기: **`▶` 커서는 하나**(D11, 권한 메뉴와 같음) — 포커스·hover한 선택지 앞, 아무것도 아니면 첫 선택지 앞. 다른 선택지의 기호 칸은 같은 24px 빈칸(`visibility: hidden`)이라 label 정렬이 그대로. 누르면 바로 보냄.
- 여러 개(`multiSelect`): 기호 `[ ]` / `[✓]`, `aria-pressed`, 카드 오른쪽 아래 `보내기`(`.btn`, 하나도 안 고르면 비활성).
- 질문이 2개 이상이면 위아래로 쌓고 맨 아래 `보내기` 하나(하나 고르기도 이때는 토글 → 보내기).
- 직접 답: 질문이 1개일 때만, 입력 줄에서 Enter. `preview`는 표시하지 않음.
- 답한 뒤: 선택지 목록이 "→ {label}" / "→ {label}, {label}" / "→ {직접 쓴 글}" / "→ 답하지 않음 (중단)"으로 접힘(픽셀 12px dark; 직접 쓴 글은 일반 글꼴).

### 2.5 끝 줄

- 글 칸에 맞춰 64px 들여씀. 완료·중단 = 픽셀 12px dark: "완료 · 추정 비용 ${total_cost_usd 소수 4자리}" / "중단됨".
- 오류 = "✕ 오류:"(픽셀 12px ink) + 4px + 사유(일반 13px ink, 글자 그대로, 줄바꿈). Orbit이 만드는 문구: node 없음·버전 미달 "Node.js 18.14 이상이 필요합니다 — node를 찾지 못했습니다"/"— 지금 {버전}". SDK 오류(로그인 안 됨 포함)는 SDK 문구 그대로(토큰 문자열이 섞여 있으면 Engineer·Security 판단으로 가림).
- 비용이 없는 결과(오류)는 비용을 적지 않는다.

### 2.6 입력 줄

- 높이 최소 44px, 패딩 4px 4px 4px 12px, 사이 8px, 기록과 사이 8px.
- 입력칸 = `textarea` 1줄 시작, 3줄(58px)까지 늘고 넘치면 안에서 스크롤. Enter = 보내기, Shift+Enter = 줄바꿈. 포커스 링은 입력 줄 전체(2px ink, offset 2px).
- 꺼짐/실행 중 = 2px 점선 dark(기존 `border.input-disabled`), 켜짐 = 2px 실선 ink. 실행 중 문구는 픽셀 12px dark, 넘치면 말줄임.
- 기존 "⑥에서 연결" 칩은 없앤다.

### 2.7 긴 응답·스크롤

- 기록은 세로 스크롤, 스크롤 막대 ink/light(그래프와 같음). 맨 아래에 붙어 있으면 새 글이 올 때 따라 내려가고, 사용자가 위로 올려 읽는 중이면 그 자리를 지킨다. 시안은 바깥 `flex-direction: column-reverse` + 안쪽 정순 목록으로 이 동작을 얻는다(Engineer가 그대로 써도 됨, DOM 순서는 정순).
- 새 카드가 뜨면 위치와 상관없이 카드가 보이게 스크롤한다(실행이 멈춰 있으므로).
- "맨 아래로" 버튼은 만들지 않는다.

## 3. 토큰

재사용: `color.ink/dark/light/paper`, `font.family.pixel/body/mono`, `font.size.meta/pixel/body`, `border.chip`(내 말 상자·첫 줄 점선 굵기), `border.node`+`node-shadow`+`radius.node`(카드), `border.input-disabled`, `border.box`(켜진 입력 줄), `space.1~4`, `motion.blink`, 기존 `.btn`·`.empty`·`.tag`·`.sr`·`.blink`.

새 토큰 (`chat.*`):
- `who-col` 56px — "Claude" 픽셀 6자 + 여유. `text-indent` 64px = who-col + 8px, 카드·끝 줄 들여쓰기.
- `msg-gap` 8px — 항목 사이. `caret` 7×13px — 본문 한 글자 높이.
- `card-max` 640px — 넓은 칸(1034px)에서 메뉴가 너무 퍼지지 않게.
- `cmd-max-height` 117px — 고정폭 13px×1.5×6줄.
- `input-min-height` 44px — 버튼 24px + 위아래 여백. `input-max-height` 58px — 3줄.
- `option-gap` 16px — 권한 메뉴 항목 사이.

## 4. 접근성

- 기록: `role="log"`, `aria-label="대화"`, `tabindex="0"`(키보드 스크롤). 스트리밍 글 변화는 낭독하지 않는다. 대신 패널 안 시각 숨김 `role="status"` 하나가 큰 사건만 읽는다: "Claude가 답하는 중", "권한 요청: {도구}. 채팅에서 허용, 거부, 이 세션 동안 중 고르세요", "질문: {header}", "완료 · 추정 비용 $…", "중단됨", "✕ 오류: …".
- 카드가 떠도 포커스를 옮기지 않는다(읽는 중 빼앗지 않음). Tab 순서: `새 대화` → 기록 → 카드 대상(스크롤될 때) → 카드 버튼 → 입력 줄.
- 카드 = `role="group"` + `aria-labelledby`(질문 줄). 권한 메뉴 버튼 이름 = 보이는 글자("이 세션 동안 (이 명령만)" 전체). `▶`·`[✓]`·커서·`▼`는 `aria-hidden`; 다중선택 상태는 `aria-pressed`.
- 입력칸 `aria-label`: "Claude Code에게 보낼 말" / 질문 대기 시 "선택지에 없는 답".
- 중단 중 비활성 버튼은 `aria-disabled`(포커스를 잃지 않게, roadmap run REVIEW W4와 같은 문제 예방).
- 대비: 본문·이름표·카드 ink/paper 16:1, 보조(dark)/paper 6.0:1, hover(light) 위에는 ink만 쓴다(description도 hover 때 ink로; dark/light 3.1:1 회피).
- 포커스: 기존 2px ink outline, offset 2px. 기록·카드 대상 스크롤 영역은 안쪽 4px 여백으로 링이 잘리지 않게.
- 클릭 영역 ≥24px(버튼·선택지·메뉴 항목).
- 움직임: 커서·`▼`는 `.blink` → reduced-motion이면 멈춤(기존 규칙).

## 5. 결정 (열린 질문 답, D11 — 2026-11-15)

1. 질문 카드 `▶`: **커서 하나로 통일** — 고른(포커스·hover) 선택지 앞에만, 기본은 첫 선택지. 시안 변형 6 반영. 여러 개 고르기의 `[ ]`/`[✓]`는 그대로.
2. 내 말 = 이름표 "나" + 얇은 테두리 상자, 오른쪽 정렬 없음 — 시안 그대로.
3. 답의 마크다운은 해석하지 않고 글자 그대로. 해석은 뒤 run.
4. 960×640에서 대화 영역 약 5줄 — 시안 그대로 수용.

6. 실행 중 입력 줄 = 점선 dark + 문구 "Claude가 일하고 있다…"(권한·질문 대기 땐 "고를 때까지 기다리고 있다…") + 오른쪽 `중단`.

8. 권한 대상 고르기: Bash=command, Edit/Write/Read/NotebookEdit=파일 경로, WebFetch=url, 그 밖=입력 JSON 한 줄 300자.
9. 권한 메뉴 = 테두리 없는 픽셀 글자 버튼 3개(높이 24, 사이 16), `▶` 커서 하나(포커스·hover, 기본 허용 앞), hover 바탕 light. 문구 `허용` / `거부` / `이 세션 동안 (이 명령만)` · `이 세션 동안 ({도구} 전부)`.
10. 답한 카드 = 메뉴 대신 결과 한 줄(픽셀 dark): "→ 허용함" / "→ 거부함" / "→ 이 세션 동안 허용함 (…)" / "→ 거부됨 (중단)".
11. 카드가 떠도 포커스 이동 없음, `role="status"`로 알림. 새 카드는 보이게 자동 스크롤.
12. 질문 카드: header = `.tag` 칩, 질문 = 일반 13px, 선택지 = 세로 목록(기호 24px + label 픽셀 12px / description 일반 11px dark). 하나 고르기 = `▶` 커서 하나(포커스·hover, 기본 첫 선택지, 나머지는 24px 빈칸 — D11), 누르면 바로 보냄. 여러 개 = `[ ]`/`[✓]` 토글 + 카드 오른쪽 아래 `보내기`(0개면 비활성). 질문 2개 이상 = 쌓고 `보내기` 하나.
13. 직접 답은 질문 1개일 때만 입력 줄로(placeholder "다른 답은 여기에 쓰고 Enter", `보내기` + `중단`). 답한 질문 카드 = "→ {답}" 한 줄, 중단 시 "→ 답하지 않음 (중단)".
14. 끝 줄 64px 들여씀: "완료 · 추정 비용 $0.0123"(소수 4자리, 픽셀 dark) / "중단됨"(픽셀 dark) / "✕ 오류: {사유}"(✕ 오류: 픽셀 ink + 사유 일반 13px ink).

16. 빈 상태 문구: 미선택 "세션을 고르면 그 폴더에서 대화를 시작합니다"(BRIEF 그대로), 선택됨 "보내면 {이름} 폴더에서 새 대화를 시작합니다".
17. 입력 줄 = textarea 1→3줄(58px) 자람, Enter 보내기·Shift+Enter 줄바꿈, 최소 높이 44px, 켜짐 실선 ink·꺼짐/실행 중 점선 dark, 포커스 링은 줄 전체, `보내기` 버튼 추가(빈 글이면 비활성), "⑥에서 연결" 칩 삭제. `▶`·`▼`(켜짐에서만 깜빡임) 유지.
18. 스크롤: 맨 아래면 따라가고 위로 올렸으면 유지(column-reverse 방식), "맨 아래로" 버튼 없음.
19. 중단 누른 뒤 `중단`은 `aria-disabled`로 비활성(글자 그대로).
20. 시안 예시 데이터: 폴더 "proj", BRIEF 성공 기준 5·8·10·11·13의 프롬프트, 비용 $0.0123/$0.0214, 사과/배(/귤) 설명 "새콤하고 아삭함"·"달고 물이 많음"·"껍질을 손으로 깜"(실제 앱에서는 Claude가 쓰는 description이라 글은 달라짐).
